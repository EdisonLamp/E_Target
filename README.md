This is a target system, designed to detect the impact of munition on a flat surface.

This project useds 4 vibration detecors (piezo) and a overclocked raspberry pico to messure the time difference betwen the 4 edges on the impact plate.

It displays the mesurments using a web interface.

This is hardly inspired by an article published in the Make magazine 6/2018. Big thanks to Marcus Höller-Schlieper <3 

The main improvements I made:
- Using less complicated electronics
- getting finer mesurments c.a. 4 Msps
- calculating on board
- using web ui to secure compatiblity
